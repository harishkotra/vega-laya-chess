# Third-party notices

This repository contains no model weights. It downloads them, with the user's
explicit consent, from the repositories below.

## The decision model

| what | repository | licence | size |
| --- | --- | --- | --- |
| decision engine + adapters | `nandakishorm/vega-08b-public-intents` | Apache-2.0 | ~70 MB |
| frozen backbone | `Qwen/Qwen3.5-0.8B` | Apache-2.0 | ~1.77 GB |
| inference package | `vegaml` on PyPI | Apache-2.0 | n/a |

The checkpoint repository also publishes a 4B model. The download allow-list in
`app/model_manager.py` skips it deliberately: this app never loads it, and its
backbone is roughly 15 GB in float32.

## Position data

| what | source | licence |
| --- | --- | --- |
| `lichess-*.jsonl` positions and published solutions | `Lichess/chess-puzzles` on the Hugging Face Hub | CC0-1.0 |
| `demo-*.jsonl` positions | generated by `scripts/make_demo_positions.py` | MIT, same as this repo |

Every label in every set is re-derived by exhaustive search. For the Lichess
sets the row also records whether the published solution agrees with the search,
and the report counts the disagreements instead of hiding them.

## Build tooling

| what | licence | where it is used |
| --- | --- | --- |
| `python-chess` | GPL-3.0 | `scripts/` and `tests/` only, to generate and verify ground truth, and to check the app's own rules engine |
| `laya` + Laya 421M | Apache-2.0 | a second local decision model, run through the `laya` package and the `convaiinnovations/laya-multilingual` checkpoint |
| Vega 0.8B + `vegaml` | Apache-2.0 | the primary local decision model and the package that runs it |
| `pyarrow`, `huggingface_hub` | Apache-2.0 / MIT | `scripts/fetch_positions.py` only |

`app/` and `web/` import neither python-chess nor pyarrow. The shipped
application is MIT; the GPL tooling is a build-time dependency that a user
installs separately, and the generated data files it produces are not a
derivative work of it.

The game needs a rules engine, and the app has its own: `app/chess_rules.py`,
written from scratch under this repo's MIT licence. `tests/test_chess_rules.py`
compares it against python-chess move by move, which is a test-time dependency
only. Nothing GPL ships inside the application.

## Front end

No third-party JavaScript. `web/` is plain DOM, plain `fetch`, and hand-written
SVG. No CDN, no font download, no telemetry.
